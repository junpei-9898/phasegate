# プロンプトパターン

タスクタイプ別のcodex exec プロンプトテンプレート。3層構造（コンテキスト層・タスク層・制約層）に従う。

---

## 共通コンテキスト層

全タスクタイプで以下をプロンプト冒頭に含める:

```
プロジェクト: Phasegate
アーキテクチャ: ヘキサゴナル + DDD（domain → port → usecase → controller）
```

- 既存テストを壊さないこと
- 他の正常な箇所を書き換えないこと
```

## プロンプト設計の鉄則

1. **具体例 > 抽象的な指示**: 「AAAパターンに従え」→ OK/NGコード例を添付
2. **ホワイトリスト > ブラックリスト**: 「これ以外は変更するな」→ 「以下のファイルのみ変更可」
3. **参照ファイルのパス + 抽出内容**: ファイルを読めと言うだけでなく、重要なルールをインライン引用
4. **1委任単位 = 1明確なゴール**: 複数の目的を1プロンプトに詰め込まない
