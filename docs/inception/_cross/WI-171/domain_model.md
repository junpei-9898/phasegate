# WI-171 Domain Model

| Concept | Meaning |
|---|---|
| Onboarding Path | A route such as first-run, daily-use, CI-use, or agent-use. |
| Success State | The observable command result or installed artifact state that tells the user the path is complete. |
| Troubleshooting Finding | A `doctor` finding interpreted through severity, repair mode, repair hint, and suggested skill. |
